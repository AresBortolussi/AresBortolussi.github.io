# Portfolio v3 — proposte del 26 ottobre 2026

old1/ conserva integralmente il sito precedente al rifacimento. old2/ conserva il portfolio approvato prima di questa revisione. Sono disponibili anche i branch old1 e old2.

v3/ offre una nuova struttura CV: profilo, attività, progetti, competenze e contatti. Tre palette sulla stessa struttura, selezionabili con pulsanti o ?theme=blade|neuro|carbon. Blade: petrolio/ambra; neuro: grafite/verde fosforo; carbon: viola/ciano. Font di sistema; nessun caricamento esterno. Stampa browser con CSS dedicato. La home resta il portfolio v2 durante la scelta.

La descrizione di APE chiarisce l'origine informale durante pranzi con persone del gruppo APE INFN e l'assenza di appartenenza o affiliazione. old2 è una copia storica immutata, non una revisione editoriale.

L'esperienza è descritta per attività, senza inventare datori di lavoro, date contrattuali o qualifiche. Per trasformarla in un CV completo occorre integrare una cronologia professionale verificata e il collegamento LinkedIn corretto.

Il laboratorio AI personale è descritto come lavoro in corso. Il nuovo nucleo riutilizzabile proposto è Local Context Core: sorgenti configurabili, ricerca documentale con riferimenti, lettura note e collegamenti, API del core indipendente da Langflow, CLI e futuri adattatori HTTP/MCP. Nessuna dichiarazione di aver importato o verificato il codice attuale del Mac.
