PROGETTO PERSONALE / SCHEMI & DATABASE

SQL Toolkit

Dal modello a uno schema da discutere.

Uno strumento locale per progettare, validare e confrontare schemi database, con risultati ispezionabili prima di intervenire sui dati.

  • Python
  • SQL
  • CLI

Workbench 0.4.0a1 · versione di sviluppo

01 / IL PROBLEMA

Il problema

Un foglio di progettazione, uno schema SQL e la sua documentazione possono divergere. Serve un modello comune per controllare i riferimenti, confrontare revisioni e rendere visibili le differenze.

02 / LA SCELTA PROGETTUALE

La scelta progettuale

Una rappresentazione condivisa dello schema collega importazione, validazione, piano delle dipendenze, diagrammi ERD, documentazione e diff. La CLI funziona senza passaggi interattivi e genera file da revisionare: non esegue migrazioni sui database.

03 / COSA È VERIFICATO

Cosa è verificato

Import di modelli CSV/XLSX, import di un sottoinsieme DDL SQLite e generazione DDL per sottoinsiemi espliciti di SQLite, PostgreSQL e SQL Server. Le prove includono esecuzione sui database reali, relazioni cicliche e controlli dei vincoli. Le funzionalità non supportate vengono rifiutate anziché produrre SQL incompleto.

04 / IL PROSSIMO PASSO

Il prossimo passo

Ampliare importazione e introspezione degli schemi, continuando a trasferire i moduli esistenti sul modello comune. Il supporto attuale non equivale a una conversione generale e senza perdita fra dialetti.

05 / CONTESTO

Un progetto aperto alla discussione.

Il codice è conservato in un repository privato. Questa scheda riassume il lavoro e i suoi limiti a ottobre 2026.
