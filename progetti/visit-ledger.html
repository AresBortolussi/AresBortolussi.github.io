PROGETTO PERSONALE / C & DATI

Visit Ledger

Dalle visite a dati confrontabili.

Un registro locale delle visite ai ristoranti, con importazione multiformato, analisi di spesa e valutazioni, riepiloghi mensili e controllo dei duplicati.

  • C17
  • Python
  • Docker

2.3.0-dev.2 · versione di sviluppo

01 / IL PROBLEMA

Il problema

File con intestazioni, date e importi diversi rendono poco affidabile il confronto delle visite. La prima parte del lavoro è normalizzare gli ingressi, dichiarare gli errori e mantenere coerenti i risultati.

02 / LA SCELTA PROGETTUALE

La scelta progettuale

Un motore analitico C17, una libreria nativa riutilizzabile e una scelta esplicita del lettore: C, Python o automatica. La modalità C non avvia Python e rifiuta i formati che non supporta, senza cambiare lettore di nascosto.

03 / COSA È VERIFICATO

Cosa è verificato

Il lettore C gestisce delimitati UTF-8 e JSON/JSONL, alias delle colonne, riordino e normalizzazioni locali di date e importi. Sono state eseguite prove di equivalenza, controlli con sanitizzatori e prove sui pacchetti standalone; il lettore C è stato esercitato anche senza Python nel percorso di esecuzione.

04 / IL PROSSIMO PASSO

Il prossimo passo

Estendere il lettore nativo ai formati Excel, ODS, XML e YAML e completare la parità su codifiche e spazi Unicode. Questi formati restano disponibili attraverso gli adattatori Python; la parità completa del backend C non è ancora raggiunta.

05 / CONTESTO

Un progetto aperto alla discussione.

Il codice è conservato in un repository privato. Questa scheda riassume il lavoro e i suoi limiti a ottobre 2026.
